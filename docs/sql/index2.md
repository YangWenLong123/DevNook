## 介绍

Navicat 是一款图形化数据库管理工具，可以通过窗口、菜单和表格管理数据库，减少手动输入 SQL 的操作。

你安装的 MySQL 负责存储和查询数据，Navicat 则连接 MySQL，提供可视化操作界面。

| 功能 | 可以做什么 |
|---|---|
| 数据库连接 | 连接本机或远程服务器上的数据库 |
| 数据库管理 | 创建数据库、查看数据库结构 |
| 表结构设计 | 创建表，设置字段类型、主键、索引和约束 |
| 数据编辑 | 像操作表格一样查看、新增、修改和删除记录 |
| SQL 查询 | 编写 SQL，获得语法高亮、补全及查询结果 |
| 数据导入导出 | 在数据库与 CSV、Excel 等文件之间交换数据，具体格式取决于版本 |
| 备份与恢复 | 导出 SQL 文件，并在需要时执行恢复 |
| 数据同步 | 对比、同步不同数据库的结构或数据 |
